## Deskripsi Game
**The Little Match Girl** adalah game berbasis cerita interaktif yang diadaptasi dari dongeng karya Hans Christian Andersen. Pemain akan mengendalikan seorang gadis kecil penjual korek api yang berjuang bertahan di tengah musim dingin dengan berbagai pilihan sulit. Setiap keputusan membawa konsekuensi dan mengarah ke salah satu dari 15+ ending yang emosional.


## Instalisasi

Game ini diharuskan menggunakan library graphics.h dan juga mingw32 bit. Berikut cara penginstalannya :
1. Instalisasi library raylib sesuai dengan https://www.raylib.com/
2. Clone https://github.com/Arumannn/The-Little-Match-Girl
3. Lakukan compile dengan menekan **Win + Shift + B** pada mastermain.c
4. Jika tidak bisa menggunakan tombol compile tersebut maka buka terminal dan masukan perintah `gcc -Iinclude main.c src/mainmenu.c src/minigame.c src/story.c src/Stack.c src/customstory.c -o main -lraylib -lopengl32 -lgdi32 -lwinmm
5. Maka akan muncul file output.exe, Execute file tersebut dengan klik kanan lalu pilih `Run executable`
6. Jika tidak bisa maka buka terminal. lalu ketikan perintah `./main.exe`

## Guide to Play
Tujuan dari game ini yaitu mencari seluruh ending yang variatif dengan memilih keputusan-keputusan yang di sediakan
